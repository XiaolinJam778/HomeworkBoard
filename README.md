# HomeworkBoard

HomeworkBoard is a lightweight Windows desktop application for managing university assignments and deadlines

## Planned Features

- Add, edit and delete assignments
- Track assignment deadlines
- Mark assignments as completed
- Sort assignments by deadline
- Highlight upcoming and overdue assignments
- Store data locally with SQLite
- Desktop widget mode

## Tech Stack

- Python
- Tkinler
- SQLite
- Git / GitHub
